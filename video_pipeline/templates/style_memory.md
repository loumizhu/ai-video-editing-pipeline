# Style Memory (channel-level taste layer)

> Location in production: `Videos-Scripts/_style_memory/style_memory.md` (copy this template there once).
> Read at Stage 03 and Stage 06 of every video. Updated by the agent after G4 from the owner's feedback (`edit_report.md` section 6).
> **Taste, not law:** a style rule can never relax a hard still-hold cap, a licence rule, a truth tier or a naming rule.
> Bounded: **max 40 active rules**. Merge or retire before adding. Newest wins on conflict unless a rule is `always`.
> Promotion: a rule confirmed on 3 videos is proposed to the owner for `bake-preset`. Agents never edit presets, and never change an `always` rule, without the owner.
